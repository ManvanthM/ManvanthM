# 🚀 Featured Work

## 🧠 Telecom Churn Prediction & Explainable ML Platform

**Python · Flask · Scikit-learn · XGBoost · LightGBM · CatBoost · SHAP · SQLite · Power BI**

An end-to-end ML product that predicts telecom churn and turns predictions into actionable retention insights.

**Highlights**
- **85.90% accuracy · 92.25% AUC** reported by the optimized project evaluation
- Single-customer prediction + bulk CSV inference
- SHAP-based explanations for prediction drivers
- Risk classification and analytics dashboard
- Personalized retention email generation
- Power BI reporting and model-performance visualizations

**Architecture**

```text
Customer Data
     ↓
Preprocessing & Feature Engineering
     ↓
Ensemble ML Pipeline
     ↓
Churn Probability / Risk
     ├───────────────┐
     ↓               ↓
SHAP Explainability  Analytics Store
     ↓               ↓
Retention Actions   Dashboard / Power BI
```

🔗 **[Explore the project →](https://github.com/ManvanthM/ml-new-churn-prediction)**
